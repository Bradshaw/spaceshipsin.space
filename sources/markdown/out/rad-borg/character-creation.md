# Character Creation - Räd Borg

## Lifeform

Choose or roll d4:
1. Mutant
2. Dirtling
   1. Fungi
   2. Plant
3. Robot
4. Cyborg

## Stats

### Abilities

Choose whether to roll for abilities or pick a standard array. The stardard arrays give a total of +2, whereas rolling gives an average of +2.56.

Once you have your array of four scores, assign them as you like to Moves, Smarts, Muscles, and Guts

#### Rolling for abilities

For each score, roll 4d6 and drop the lowest, get the final score from this table:
- 1-4: -3
- 5-6: -2
- 7-8: -1
- 9-12: ±0
- 13-14: +1
- 15-16: +2
- 17-20: +3

#### Standard arrays

Balanced: +1 / +1 / ±0 / ±0
Spicy: +2 / +1 / ±0 / -1

### Vitals

Hitpoints: Begin with Guts + d8 (worst case 1HP, never less)
Flexes: Begin with Moves + d2 (worst case 2 flexes, never less)
Magicks: Begin with Smarts + d4 (worst case 1 magick, never less)

## Gear

Start with 2d6 × 10 Bits and either d4 snacks or d4 batteries.
Mutants, dirtlings and cyborgs start with a Thermos with four days of drinking water.
Robots start with d4 spare parts.
